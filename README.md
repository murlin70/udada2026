# 화랑, 서라벌을 걷다

경주 도보여행 사전 특강을 위한 **웹 기반 한국사 학습 게임 모음**입니다.
설치도 로그인도 필요 없고, 학생들이 각자 휴대전화 브라우저에서 링크만 열면 바로 실행됩니다.

- 그래픽·음악을 모두 코드로 만들어 **외부 이미지·음원 파일이 하나도 없습니다** (저작권 걱정 없음)
- 전체 용량 **100KB 남짓**. 데이터가 거의 들지 않습니다
- 라이브러리는 RPG 스타터의 Phaser 3(MIT) 하나뿐이고, 게임 1·2는 순수 HTML·CSS·JS입니다

## 게임 소개

### 1. 경주 왕경 탐험 — 문화유산 탐사대

화랑이 되어 세 구역을 달리며 문화유산 21점을 모으는 횡스크롤 게임입니다.

- **구역 3개** — 월성과 계림 / 첨성대와 대릉원 / 토함산과 불국사 (구역당 9,300~11,500px)
- **적 3종** — 도깨비(순찰), 호랑이(빠름), 역신(공중 부유). **위에서 밟으면** 물러갑니다
- **처용** — 적이 아니라 도우미입니다. 처용가·처용무는 역신을 노래와 춤으로 물리친 이야기라,
  처용을 만나면 9초 동안 무적이 되고 닿는 적이 모두 물러갑니다
- **지형** — 계단, 발판 건너기, 움직이는 발판, 높은 발판
- **중간 지점** 2곳, 하트 3개, 구역 끝 확인 문제 1문항
- **배경음악** — 78BPM 계면조 5음계, 가야금 같은 튕김과 장구의 덩·덕 패턴

### 2. 천년의 문 — 한국사 시간여행

수학여행 중 첨성대에 손을 댄 순간 신라 천년으로 떨어지는 비주얼노벨입니다.

- **6세기 진흥왕** 화랑 풍월과 세속오계 → **7세기 선덕여왕** 첨성대와 황룡사 9층 목탑
  → **8세기 경덕왕** 불국사 석공과 성덕대왕신종 → **935년** 무너진 서라벌 → 다시 2026년
- **지식 · 용기 · 인연** 스탯이 선택마다 오르고, 조합에 따라 **엔딩 4종**이 갈립니다
- 확인 문제 4문항, 선택지 6곳, 자동 재생 · 백로그 · 저장 · 글자 속도 조절
- **배경음악이 시대마다 바뀝니다** — 현대는 밝은 5음계, 7세기 밤은 낮고 느린 계면조,
  8세기 절은 종소리 음색, 935년 폐허는 가장 성글고 낮은 소리

### 3. 신라 1000년 RPG 스타터 (학생 제작용)

Phaser 3 기반 탑다운 RPG입니다. 코드 안에 `[고치기 1~4]` 표시가 있어
지도·인물·유물·문제를 학생이 직접 바꿔 자기만의 왕경을 만들 수 있습니다.
특강이 아니라 **도보여행 이후 사후 활동**으로 쓰기를 권합니다.

## 학생에게 안내할 것

- 앱 설치·로그인 없음. 링크만 열면 됩니다
- 기록은 **각자 휴대전화에만** 저장됩니다 (교사가 원격으로 볼 수 없음)
- 그래서 **마지막 결과 화면을 캡처해 제출**하는 것을 규칙으로 정하세요
- 게임 1·2 모두 배경음악이 있습니다. 시작 화면에서 **소리 끄고 시작**을 고를 수 있고,
  진행 중에도 소리 버튼으로 끄고 켤 수 있습니다
- 중간에 나가도 다시 들어오면 이어서 할 수 있습니다

## 내용 고치기

교사가 직접 손보기 쉽도록 데이터와 엔진을 분리해 두었습니다.

| 고치고 싶은 것 | 열 파일 | 찾을 곳 |
|---|---|---|
| 게임 1의 지형·길이 | `game1.html` | `STAGE_DEFS`의 `sec` 배열 (`flat` 평지, `gap` 구덩이, `steps` 계단, `pit` 발판 건너기, `mover` 움직이는 발판) |
| 게임 1의 유물·적 | `game1.html` | `RELICS`, `STAGE_DEFS`의 `relics` · `enemies` |
| 게임 2의 대사·선택지·문제 | `game2.html` | `STORY` 배열 |
| 게임 2의 시대별 음악 | `game2.html` | `MOOD` (조성·템포·음색) |
| RPG의 지도·인물 | `rpg.html` | `MAP`, `NPCS`, `RELICS`, `QUIZ` |

게임 1의 지형을 고칠 때는 **점프 최대 높이가 약 144px**이라는 점만 기억하세요.
그보다 높은 발판은 올라갈 수 없습니다.
